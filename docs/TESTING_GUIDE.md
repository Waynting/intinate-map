## 📋 測試步驟

### Step 1: 註冊測試帳號

1. 打開瀏覽器訪問: **http://localhost:5173**
2. 頁面會自動重定向到登入頁面 (`/auth/login`)
3. 點擊「註冊」或訪問: http://localhost:5173/auth/register
4. 使用 Demo 帳號登入:
   ```
   一般用戶:
   Email: demo@intimate-spaces.com
   Password: demo1234

   管理員:
   Email: admin@intimate-spaces.com
   Password: admin1234
   ```
5. 註冊成功後會自動登入並重定向到地圖頁面

**預期結果:**
- ✅ 成功註冊
- ✅ 自動登入
- ✅ 重定向到 `/places` 頁面

## 🐛 常見問題排查

### 問題 1: 前端頁面空白
**症狀:** 打開 http://localhost:5173 看到空白頁面

**解決方案:**
1. 檢查瀏覽器 Console (F12)
2. 查看是否有 JavaScript 錯誤
3. 檢查前端服務器是否運行:
   ```bash
   curl http://localhost:5173
   ```
4. 重啟前端服務器:
   ```bash
   cd frontend
   npm run dev
   ```

---

### 問題 2: API 請求失敗
**症狀:** 登入/註冊失敗，顯示網路錯誤

**解決方案:**
1. 檢查後端服務器是否運行:
   ```bash
   curl http://localhost:3000/health
   ```
   應該返回: `{"status":"ok"}`

2. 檢查 CORS 設定:
   - 後端應該允許 `http://localhost:5173`
   - 查看後端啟動日誌的 "CORS Origins" 欄位

3. 重啟後端服務器:
   ```bash
   cd backend
   npm run dev
   ```

---

### 問題 3: 地圖不顯示
**症狀:** 地圖區域空白或顯示錯誤

**原因:**
- Google Maps API Key 未設定或無效

**解決方案:**
1. 檢查前端 `.env` 檔案:
   ```bash
   cat frontend/.env
   ```
   應該包含:
   ```
   NEXT_PUBLIC_GOOGLE_MAPS_JS_KEY=你的API金鑰
   ```

2. 如果沒有 API Key:
   - 訪問: https://console.cloud.google.com/
   - 啟用 Maps JavaScript API
   - 創建 API Key
   - 更新 `.env` 檔案
   - 重啟前端服務器

---

### 問題 4: 沒有場所資料
**症狀:** 地圖上沒有標記，列表空白

**原因:**
- 資料導入尚未完成或失敗

**解決方案:**
1. 檢查導入進度:
   - 查看背景進程輸出
   - 應該看到 "Progress: X/15388"

2. 檢查資料庫:
   ```bash
   cd backend
   npx prisma studio
   ```
   打開 `Place` 表，查看是否有資料

3. 手動導入（如果導入失敗）:
   ```bash
   cd backend
   npm run import:hotels -- --skip-google
   ```

---

### 問題 5: 評論提交失敗
**症狀:** 點擊「提交評論」後顯示錯誤

**可能原因:**
1. 未登入 → 重新登入
2. 後端 API 錯誤 → 檢查後端日誌
3. 評分未選擇 → 確保選擇了星級

**檢查步驟:**
1. 打開瀏覽器 DevTools (F12)
2. 切換到 Network 分頁
3. 提交評論
4. 查看 `/api/reviews` 請求
5. 檢查回應的錯誤訊息
